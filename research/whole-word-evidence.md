# 완성 영문 판독과 오른쪽 Shift 교정

2026-10-26. 기준 커밋은 `72ae0ba7716e6058e14385fb10a4554e61e3bdf1`이다. `goal`을 자동 판독하고, 현재 단어를 오른쪽 Shift 한 번으로 교정하는 변경이다. 단어·약어 목록, 모델 데이터, libhangul 원본은 추가하거나 수정하지 않았다.

## 판독 변경의 범위

`goal`은 `해미`로 완전히 조합되며 두 음절 모두 기존 자료에 있다. 기존 점수는 개별 음절의 익숙함과 단어 전체의 연결 근거를 구분하지 못했다. 이제 완성 영문 형태에 **관측된 연속 모음과 모든 문자 연결**이 있을 때, 경쟁 한글의 단어 연결 근거도 비교한다. 한글에 관측된 음절 쌍·반복 음절·강한 조사/어미 근거가 있으면 보존하고, 그렇지 않을 때만 기존 연결 비용을 적용한다. 구체적인 조건은 [후보 정책](../docs/decoder-policy.md)을 따른다.

이 범위를 무작정 넓히지는 않았다. 연속 모음 근거 없이 적용하면 `핸드·새해·야생`이 영문으로 바뀌었고, 혼합 경계 보호까지 풀면 `미약한·야생동물의`가 분리됐다. 이 변경들은 제외하고 반례를 회귀 검사에 남겼다. 기존 혼합 경계 보호는 유지한다. 자료의 미관측을 곧바로 다른 언어의 증거로 쓰는 데 한계가 있다는 뜻이다.

## 같은 자료에서 비교한 결과

[측정 원본](whole-word-metrics.tsv)은 이전 [표시 안정성 평가](typing-stability.md)와 동일한 실행 코드·공개 말뭉치·세 문맥을 사용한다. 자료의 리비전·SHA-256·라이선스와 지표 정의는 이전 보고서에 기록되어 있다. test와 dev 모두 개발 중 재사용했으므로 블라인드 정확도가 아니다.

| 자료 | 최종 정답: 전 → 후 | 표시 정답: 전 → 후 | 반복 전환 키: 전 → 후 |
|---|---|---|---|
| EWT test | 11,419 → 11,431 / 12,060 | 73,014 → 73,077 / 82,329 | 7,157 → 7,152 |
| EWT dev | 11,240 → 11,261 / 11,895 | 72,293 → 72,377 / 81,546 | 6,976 → 6,962 |
| GSD test | 28,845 → 28,845 / 28,875 | 187,106 → 187,082 / 219,939 | 10,407 → 10,452 |
| GSD dev | 28,833 → 28,833 / 28,875 | 190,669 → 190,642 / 223,392 | 10,020 → 10,074 |

행별 대조에서 영어 test 12건·dev 21건이 새로 맞았고, 이전 정답을 틀리게 만든 건은 네 자료 모두 0건이다. 영어 dev에는 오답이 다른 오답으로 바뀐 3건도 있다. 한글 최종 출력은 두 자료 모두 전부 같다. 그러나 **한글의 중간 표시 정답은 각각 24·27프레임 줄고 반복 전환은 늘었다.** 이번 수정은 완성 영문 오판독 일부를 줄였으며 전반적인 표시 안정성 개선으로 해석하지 않는다.

기존 의도 fixture 375건은 최종 결과와 집계한 표시 지표가 모두 같다. 신규 [의도 fixture](../crates/amu-core/tests/fixtures/whole-words.tsv) 37종×3문맥에는 개선 사례와 정상 한글, 초성, 아직 실패하는 단어·혼합 입력을 함께 넣었다. [전](whole-word-trace-before.tsv)·[후](whole-word-trace-after.tsv) 키별 문자열도 보관한다.

| 신규 묶음 | 최종 정답: 전 → 후 | 표시 정답: 전 → 후 | 반복 전환 키: 전 → 후 |
|---|---|---|---|
| 영문 | 21 → 39 / 45 | 125 → 152 / 204 | 15 → 39 |
| 한글 | 45 → 45 / 45 | 193 → 193 / 273 | 77 → 77 |
| 초성 | 9 → 9 / 9 | 12 → 12 / 21 | 0 → 0 |
| 혼합 | 6 → 6 / 12 | 43 → 49 / 81 | 9 → 27 |

`goal·goals·coal·coals·soap·cheap`은 개선됐다. 반면 빈 문맥의 `goal`은 여전히 `g → go → 햄 → goal`이다. 끝까지 한글로 남던 오답을 영어로 복구하면서 전환 횟수가 늘 수도 있다. `soaps → 내멘`, `dia → 얌`, `goal고 → 해미고`, `goal를 → 해미를`도 아직 틀리며 평가에서 제외하지 않았다. 한글 `핸드·새해·야생`, `ㄹㅇ·ㄱㅅ·ㅋㅋㅋ`는 보존한다.

## 한 번 눌러 교정

macOS 자동 모드에서 오른쪽 Shift를 혼자 눌렀다 떼면 조합 중인 단어 전체를 한글↔영문으로 전환한다. 혼합 표시에서는 전체 영문부터 선택한다. 다른 글자·보조키와 함께 누르면 취소하므로 대문자·쌍자음용 Shift는 그대로 쓴다. 왼쪽 Shift, 빈 조합, 고정 모드에서는 발동하지 않는다. 이미 확정한 글자를 다시 쓰지는 않는다.

`CorrectionGesture`는 누름·뗌만 판별하고, `InputCoordinator`는 보안 입력·수명·호스트 반영, Rust `Session`은 명시적 언어 선택을 맡는다. 기존 혼합 후보 순환 `Ctrl+Shift+Space`와 지속 모드 키는 유지한다. 보안 입력·확정·reset·모드 전환에서 제스처 상태를 지운다. 한글 삭제 후 원시 키와 실제 조합이 달라졌으면 재해석하지 않는다.

Rust·FFI 77개 검사는 fmt·Clippy와 함께 통과했다. `macos:smoke`는 합성 flagsChanged/keyDown → Swift → C ABI → Rust → 실제 NSTextView에서 단독 Shift, 대문자·쌍자음, 다른 보조키, 확정·보안 입력·고정 모드·재진입을 검사했다. 실제 Telegram·브라우저의 시스템 IME 이벤트 전달과 렌더링 검증은 별도다. 설치본과 IMK 연결 이름이 충돌할 때 나오는 서버 생성 로그를 새 서버의 OS 연결 성공으로 해석하지 않는다.

## 비용과 재현

새 연결 검사는 O(n) 시간·O(1) 추가 공간이다. 기존 자동 판독 상한은 키당 O(n²), 세션 O(n), n≤64로 유지한다. 오른쪽 Shift의 전체 언어 교정은 O(n) 재조합만 하며 혼합 후보 탐색을 실행하지 않는다. 모델은 세션 준비 때 공유하고 키 처리 중 네트워크·디스크 I/O·입력 로그를 쓰지 않는다.

Apple M4 Pro의 release 코어를 순차 실행한 [전](whole-word-latency-before.txt)·[후](whole-word-latency-after.txt) 측정에서 일반 68,500키 p99는 10.7→10.1µs, 최대 길이 6,400키 p99는 235.8→233.0µs였다. 단일 실행의 변동이 포함되므로 속도가 개선됐다는 근거로 삼지 않는다. OS 이벤트 전달·화면 반영 시간은 제외한다.

```sh
mise run check
mise run macos:smoke
mise run core:stability
mise exec -- cargo run --release -p amu-core --example evaluate_stability --locked -- crates/amu-core/tests/fixtures/whole-words.tsv
mise run core:evaluate
```

말뭉치 실행은 이전 보고서의 명령을 사용한다. 수정 전 재현은 기준 커밋의 별도 복사본에서 같은 새 fixture를 지정한다. `crates/amu-core/src`의 파일을 이름순으로 읽어 상대 경로 UTF-8 바이트와 파일 바이트를 SHA-256에 누적한 식별값은 수정 전 `2583674c68ade1a2a4556ccf0060f447aab348a8f54a80b59c760a9d3a000ad7`, 수정 후 `a0c5e2d3d01741837c5b7b51fddbc9b80c4cfc38fd25671bfe2af5d2e1451ce0`이다.
