# Release 패키지 설치

현재 공개 패키지는 **Apple Silicon용 실험 버전**이다. 빌드 대상은 macOS 13 이상이며 CI는 macOS 26에서 검사한다. Intel·이전 macOS·모든 외부 앱에서의 입력 호환성을 보장하지 않는다.

## 다운로드와 확인

[Releases](https://github.com/TylerShin/amu/releases)에서 원하는 버전의 `Amu-…-macos-arm64.zip`과 `SHA256SUMS`를 같은 폴더에 다운로드한다. 터미널에서 해당 폴더로 이동해 확인한다.

```sh
shasum -a 256 -c SHA256SUMS
```

앱에는 ad-hoc 서명만 있다. **Developer ID 서명·Apple 공증은 아직 없다.** macOS가 실행을 차단할 수 있다. 출처와 파일을 확인하고 신뢰할 때만 [Apple의 앱 실행 승인 안내](https://support.apple.com/102445)를 따른다. 관리되는 Mac에서는 보안 정책상 실행이 불가능할 수 있다.

## 설치·업데이트

1. 조합 중인 글자를 확정하고 macOS 입력 메뉴에서 기존 **한국어** 또는 **ABC**를 선택한다.
2. ZIP을 푼다. Finder의 **이동 → 폴더로 이동**에서 `~/Library/Input Methods`를 연다. 폴더가 없으면 만든다.
3. 기존 `Amu.app`이 있다면 별도 폴더에 백업한 뒤, 새 `Amu.app`을 `Input Methods`에 복사한다.
4. 작업을 저장하고 로그아웃·로그인한다. 수동 복사만으로 기존 입력기 프로세스가 새 버전으로 바뀌지는 않는다.
5. **시스템 설정 → 키보드 → 텍스트 입력 → 편집 → 한국어 → Amu**를 추가하고 입력 메뉴에서 선택한다.

설치본의 버전은 앱 내부 `Contents/Resources/ABOUT.txt`와 `build.json`에서 확인할 수 있다. 이 파일은 설치된 파일의 버전이며 실행 중인 프로세스의 증명은 아니다.

소스를 사용하는 개발자는 저장소에서 `mise run macos:install`을 실행하면 빌드·백업·설치·안전한 재시작·실행 버전 확인까지 수행한다. 설치 전에 다른 입력기로 전환한다. Amu가 선택되어 있거나 종료를 거부하면 앱을 강제로 종료하지 않는다.

## 복구·제거

다른 입력기로 전환하고 작업을 저장한다. 이전 앱으로 복구할 때는 `Input Methods`의 앱을 백업본으로 바꾸고 로그아웃·로그인한다. 제거할 때는 키보드 설정에서 Amu를 제거하고 `Amu.app`을 휴지통으로 옮긴 뒤 로그아웃·로그인한다. 별도 상주 관리 프로그램은 없다.
